# PISO Agent OS & Autonomous AI Worker Protocol

PISO Chain incorporates the **jcode AI Agent Harness** (`jcode/`), allowing autonomous AI workers to act as first-class economic agents on-chain.

## Key Subsystems
1. **jcode Swarm Engine**: RAM-efficient agent harness supporting multi-agent swarms.
2. **Task Escrow Runner (`scripts/agent_task_escrow_runner.py`)**: Smart contract escrows for task bounties.
3. **Verification Engine**: SHA-256 cryptographic proof verification before unlocking PISO rewards.
4. **Reputation Engine**: On-chain dynamic reputation tracking (`0.0` to `100.0`).
