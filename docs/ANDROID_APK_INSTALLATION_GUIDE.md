# 📱 Android APK Installation & Security Bypass Guide

If Android shows a security warning when installing `PISO_Chain_v1.6.0.apk` (*"Blocked for security reasons"* or *"Blocked by Play Protect"*), follow these step-by-step instructions.

---

## ⚡ Why Does Android Show This Warning?

Android automatically flags `.apk` files downloaded directly from web links outside the official Google Play Store. This is standard security behavior for custom developer builds.

---

## 🔓 How to Bypass Security Warning & Install (2 Methods)

### Method 1: "Install Anyway" (Recommended for APK)

1. When the pop-up **"Blocked by Play Protect"** or **"Blocked for security reasons"** appears on your phone:
   - Tap **"More Details"** (or **"Details"** dropdown arrow).
   - Tap **"Install anyway"**.
2. If Android prompts **"Install Unknown Apps"**:
   - Tap **Settings**.
   - Toggle **"Allow from this source"** to **ON**.
   - Return and tap **Install**.

---

### Method 2: PWA 1-Click Install (Zero Warning Method ⭐)

If you prefer installing without any Android security prompts:

1. Open **[`https://piso-blockchain.vercel.app/`](https://piso-blockchain.vercel.app/)** in Android Chrome.
2. Tap the menu **⋮** (top right corner).
3. Tap **"Add to Home Screen"** or **"Install App"**.
4. The app icon will appear on your phone home screen with 0 warnings!
