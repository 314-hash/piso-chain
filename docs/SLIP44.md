# SLIP-44 Configurable Coin Type Registry

PISO Chain uses a configurable registry compliant with Satoshilabs SLIP-44 standards.

## Registered Coin Types
| Coin Type | Symbol | Network Name | Curve |
|---|---|---|---|
| `2026'` | PISO | PISO Chain Mainnet | secp256k1 |
| `3140'` | PISO-DEV | PISO Chain Devnet | secp256k1 |
| `60'` | ETH | Ethereum | secp256k1 |
| `0'` | BTC | Bitcoin | secp256k1 |
